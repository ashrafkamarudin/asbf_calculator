# ASBF Strategy Calculator

A simple browser-based calculator for comparing ASB financing (ASBF) with investing the same cash into ordinary ASB.

## Features

- Estimate ASBF instalments, net wealth, and returns.
- Compare ASBF with ordinary ASB using the same out-of-pocket payments.
- Try early termination years and view estimated payout and returns.
- Model up to 10 identical certificates.
- Switch between English and Bahasa Melayu.
- View a year-by-year breakdown and export it as a CSV file.

## How to use

Open `[asbf_calculator.html](https://asbf_calculator.ashrafkamarudin.com/)` in a web browser. No installation is required. An internet connection is needed to load the Tailwind CSS styling.

Enter your certificate amount, financing rate, ASB return, tenure, and other assumptions. Use the early termination button to explore payout estimates for different years.

## Notes

This calculator provides educational estimates, not a financing quotation or guaranteed return. It uses simplified assumptions for financing, dividends, instalments, and settlement. Actual bank terms, ASNB distributions, and settlement charges may differ.
